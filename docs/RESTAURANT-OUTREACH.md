## Step 1 — Deploy your cinematic-restaurants site as the live demo (3 clicks, free)
The repo `Tigha66/cinematic-restaurants` is a Next.js app with `vercel.json` — built for Vercel.
1. Go to **vercel.com → Add New → Project → Import Git Repository**.
2. Pick **Tigha66/cinematic-restaurants** (the app is in the `cinematic-restaurants/` subfolder — set
   "Root Directory" to `cinematic-restaurants` if asked). Framework auto-detects as Next.js.
3. **Deploy.** You get a live URL like `cinematic-restaurants.vercel.app` → **this is your demo link.**

That URL = the "wow" you show every restaurant.

## Step 2 — The free-sample tactic (highest converting)
For a target restaurant: clone the template, swap in their **name + a couple of their food photos**
(from their Instagram/Google) + their menu highlights → redeploy to a new Vercel URL (~15 min).
Then send the preview of THEIR site. Seeing their own restaurant already online = the close.
