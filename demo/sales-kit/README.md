# Sales Kit — Missed-Call Text-Back for London businesses

Everything you need to land your first 3–5 paying clients. Work top to bottom.

| File | What it's for |
|---|---|
| `outreach-scripts.md` | Word-for-word scripts: in-person, email, WhatsApp/DM, follow-ups, objections |
| `pricing-one-pager.md` | The offer + tiers you send/show prospects |
| `lead-list-template.csv` | 20-row prospecting sheet (import to Google Sheets) |
| `trial-tracker.csv` | Track each trial's recovered-lead count → your conversion proof |
| `roi-calculator.md` | The simple maths that makes the price a no-brainer |

## The 2-week sprint
1. **Days 1–3** — Demo is built ✅. Rebrand it per prospect (edit `tenants.json`),
   record a 60–90s Loom.
2. **Days 4–10** — Contact 20 businesses (`lead-list-template.csv` + `outreach-scripts.md`).
   Target: 3–5 free trials booked.
3. **Days 8–14** — Run trials, log recovered leads in `trial-tracker.csv`.
4. **Day 14+** — Convert with the ROI proof → first MRR.

## The one rule
**Lead with the free trial and the demo video — never the price.** Price only
comes up *after* it has recovered real leads for them. Let the result sell it.
